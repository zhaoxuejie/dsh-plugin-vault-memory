# dsh-plugin-vault-memory

> **让本地 Obsidian 知识库成为 DeepSeek Harness agent 的长期记忆与工作台。**

你的 Obsidian 笔记库，就是 AI 的"记忆"。本插件让 AI 学会**翻你的笔记、用你的笔记、往你的笔记里写东西**——而不是每次都当你是陌生人。

---

## 它解决什么痛点

### 🗂 痛点一：笔记存了 = 白存（最核心）
记了几百上千条笔记，但平时根本翻不到、用不上——"收集即遗忘"。

**解法**：插件给整个库建立**本地索引**，AI 能真正"搜索"你的笔记。你问它"我之前研究过 X 的什么结论"，它翻遍全库给你答案，**并告诉你出处是哪个文件，不瞎编**。

### 🤝 痛点二：每次跟 AI 聊天都要重新自我介绍
新会话里 AI 不知道你是谁、在忙什么项目、有什么偏好，前几轮全在解释背景。

**解法**：会话开始时，AI 自动看一眼你的库，知道你在做什么、最近记了什么，直接进入正题。

### 🧠 痛点三：AI 聊完就忘，成果不进你的知识库
让 AI 调研/规划完，产出散在聊天记录里，过两周就找不到了。

**解法**：一键把对话里的决策、结论存成笔记，自动归类、打标签，并建议它该与库里的哪些笔记关联。

### 🧹 痛点四：笔记库越用越烂，没人收拾
孤儿笔记、重复内容、该链接的没链接、引用了不存在的笔记……"笔记债"越欠越多。

**解法**：插件定期**巡检**，列出"这篇没人引用""那两篇像重复""这两篇建议互链"，**每条建议给出理由，你点批准它才动手**——AI 绝不乱改你的笔记。

### 🔍 痛点五：想找"意思相近但字不一样"的内容
关键词搜不到同义表达（搜"如何省钱"找不到写"消费降级"的笔记）。

**解法**：可选开启**语义检索**——本地小模型理解意思，不花钱、内容不出电脑。

---

## 为什么是 DSH 插件，而不是又一个 Obsidian 插件

Obsidian 生态里已有不少 AI 插件，但它们都困在 Obsidian 应用**内部**。而 DeepSeek Harness 是一个**整天帮你干活的 AI 工作台**——写代码、调研、规划都发生在这里。

这个插件把两件事打通：

> **干活（DSH 会话） ↔ 记忆（Obsidian 库）**

AI 干活前能查你的积累，干完活能把成果存回去，还会定期维护知识库的健康。**你的笔记从此是活的资产，不是收藏的坟场。**

---

## 给谁用最值

**笔记重度用户**——积累了好几年、笔记几百上千篇、想让 AI 真正用上自己的积累、且在意笔记隐私不外传的人。

- 库只有十几篇？暂时用不上；
- 库**越大、越乱、越久**，它越值钱。

---

## 设计原则

- **隐私优先，默认全本地**：索引、检索、巡检全部在本机完成，vault 内容默认不出机器；语义嵌入默认用本地模型（Ollama），可选切换兼容云端端点（切换时会明示）。
- **只建议，不擅改**：所有对笔记的写入都要用户逐条批准，可随时回滚。
- **溯源防幻觉**：AI 引用笔记内容必须给出文件路径，找不到就明说没有。

## 安装与使用

```bash
# 安装到目标 profile（web profile 需重启后生效）
dsh plugin --profile web add <本仓库路径>

# 配置 vault（插件设置页，或 settings.yaml）：
#   dsh-plugin-vault-memory:
#     vaults:
#       - path: D:\projectObsidian\moqian-note
#         label: note
```

装好后，在会话里直接说"查一下我知识库里关于 X 的笔记"即可。agent 会调用：
- `vault_search` 全文检索（中文 bigram 分词 + 短查询子串兜底）
- `vault_query` 结构化查询（目录/标签/时间/frontmatter）
- `vault_read` 带行号读单篇
- `vault_search` 支持 `mode=fts`/`semantic`/`hybrid`（语义依赖本机 Ollama + bge-m3，不可用时自动回退全文）
- `vault_related` 关联笔记（入链/出链/同标签/共引，带理由）
- `vault_capture` 一键把会话产出存成笔记（自动 frontmatter + 关联建议）
- `vault_health` 巡检报告：孤儿/断链/缺目录总览建议清单（`run=true` 立即巡检；只生成建议，绝不静默改库）

所有引用都强制带笔记路径；找不到就明说，不会编造。

新会话开始时会自动注入一段**记忆快照**（库状态 + 活跃项目 + 近期笔记），AI 不用从零认识你。

**Web GUI**：重启 web profile 后，浏览器右下角出现「📚 知识库」胶囊 —— 浮卡含**概览**（各库健康/断链/待审数/待审趋势/语义状态/近期更新）、**捕获**（预览→保存，成功后可在 Obsidian 打开）、**审查**（巡检建议逐条批准/忽略；孤儿可勾选要关联的笔记、断链可下拉选修复目标；写回前自动备份可回滚）、**配置**（在线增删 vault、开关注册即写入 `settings.yaml`）。每日 03:00 自动巡检（可在设置关掉或改小时）。
> 说明：DSH 设置页「Plugins → Plugin configuration」里的插件卡片需要第一方 React/tsdown.client 构建链（bundle purity gate 禁止第三方引用其表单模型），本插件走零构建纯 DOM 路线，故用右下角浮卡承担面板职责；配置经浮卡或直接编辑 `settings.yaml`。

**语义检索**：本机 Ollama（`ollama pull bge-m3`）运行且配置 `embed.enabled=true` 后，新笔记自动分块嵌入；首轮全量嵌入按库大小需数十秒到数分钟（概览会显示覆盖进度与"语义检索就绪"）。

**开发**：

```bash
pnpm install   # link 安装模式下必需（依赖从仓库路径解析）
npm test       # 76 项单测
```
